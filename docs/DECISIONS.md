# Decisions Log

Running log of non-obvious choices made during the autonomous build. Format: date — decision — rationale.

- 2026-05-29 — **Stack as scaffolded:** Next.js 16.2.6 + React 19 + Tailwind v4 (CSS-first `@theme`, no `tailwind.config.js`). — create-next-app latest defaults; aligns with brief's Next/TS mandate.
- 2026-05-29 — **Content layer = file-based MDX** under `/content`, accessed only via `src/lib/content/*`. — Brief requires unattended build with no API keys; keeps a clean seam for a future Sanity/Payload swap.
- 2026-05-29 — ~~Brand palette = neutral ramp + single indigo/blue accent placeholder.~~ **SUPERSEDED below.**
- 2026-05-29 — **Official brand kit applied (Pishon Design Studio, Apr 2026).** Palette: Forest Green `#20493B` (brand — logo, primary surfaces, footer, inverse bands), Ember Red `#C75334` (the single accent — primary CTAs, links, eyebrows, focus ring), Cream `#F7F1E0` (warm alternate-section background), warm Khaki-tinted neutrals (hairlines/muted). Fonts: Montserrat (display / H1 / H2 headlines) + Inter (body / UI). Real logo assets copied to `public/brand/`; favicon = brand mark. — Client supplied the kit. **Dark theme removed entirely** (light-only, `color-scheme: light`) per client direction; design tightened toward minimal/clean: toned-down warm-tinted shadows, khaki hairlines, deeper whitespace, and a forest-green footer as the single deliberate dark anchor. All tokens centralised in `src/app/globals.css` so the palette stays one-file editable.
- 2026-05-29 — **Forms post to stub route handlers** that validate + log + return success when integration env vars are absent. — Brief mandates swappable integration layer; no keys available in build env.
- 2026-05-29 — **Analytics + cookie consent = env-gated stubs**, default-decline. — Privacy-first requirement; no provider chosen yet.
- 2026-05-29 — **Services & Industries detail pages = single dynamic `[slug]` route** (not 14 per-slug folders), with `generateStaticParams` + `dynamicParams=false` pulling slugs from `src/lib/site.ts`. — Pages are data-driven; one route is cleaner and keeps slugs single-sourced. Statically prerendered, so SEO/SSG is unaffected.
- 2026-05-29 — **Insights uses a single `[slug]` dynamic segment** (scaffold placeholder) instead of separate `/insights/[category]` and `/insights/[slug]`. — Next.js forbids two different dynamic slug names at the same route level; a single segment dispatching article-vs-category is the standard resolution. insights-engine owns `src/app/insights/**` and will implement the real dispatch + generateStaticParams.
- 2026-05-29 — **Category archives live at `/insights/category/[category]`, not `/insights/[category]`** (brief §5/§7 wanted the latter). — Next.js forbids two differently-named dynamic segments at the same level, and articles already own `/insights/[slug]`. Nesting archives under a static `category` segment is the standard, SEO-fine resolution: clean lowercase-hyphenated URLs, one indexable page per category, breadcrumbs intact. The hub's category filter and article-page category badges link to `/insights/category/[category]`. `generateStaticParams` pre-renders only categories with ≥1 published article (`getAllCategories`), `dynamicParams=false`.
- 2026-05-29 — **"Restrained futurism" design revamp (reconciled with client).** A dark-first/cyan/shadcn brief was reconciled to the approved brand: **light theme stays default**, a polished **on-brand dark mode** (deep forest-green canvas `#0b1612`, class-based `@custom-variant dark`, no-FOUC init script, persisted toggle) is added as opt-in; **Ember Red kept as the only accent** (no cyan); **re-skin in place** (no shadcn migration). Craft added: JetBrains Mono technical labels (eyebrows/stats via `--font-geist-mono`), commanding Montserrat display type, a fixed low-opacity grain overlay, and ONE subtle aurora gradient-mesh moment on the home hero (brand greens + ember, reduced-motion gated). Purely visual — routes, metadata, JSON-LD, sitemap, MDX, forms unchanged. See `.claude/skills/restrained-futurism/SKILL.md`, `docs/DESIGN-REVAMP-BRIEF.md`, `docs/DESIGN-QA.md`.
- 2026-05-29 — **Insights hub search = client island over server-rendered list; pagination = real server-side `?page=N` slice (9/page).** — Crawlable-first: the full paginated grid + featured + category links render as static HTML (every article reachable, no-JS works). The search island receives all article metadata as props and only overrides the server grid while a query is active; cleared, it defers back to the paginated view. Out-of-range `?page` returns 404 to avoid thin soft-404s. `rel=prev/next` link hints emitted for crawlers.
